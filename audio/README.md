BST recap, course introduction, and the four-order B-tree to red-black-tree
transition.

## avl/new

The current AVL recordings, covering the lesson through the end of the
deletion examples, before the section beginning with `AVL 整个体系能够成立还需要论证`.

## avl/legacy

The older AVL recordings retained because the new recordings do not cover the
proof, balance-factor, and code sections after the deletion examples.

of any current article source.

`outputs/avl-prep/avl-asr-all.json` and the existing old AVL recap remain as
historical artifacts. The old recap can be played, but its original full
source set is no longer available for a clean rebuild because superseded takes
were deleted.
